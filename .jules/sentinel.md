## 2024-06-03 - Weak PRNG for Security-Sensitive Identifier
**Vulnerability:** The application was generating its device identifier (`device_id`) using `Math.random()`, which is a weak pseudo-random number generator (PRNG) and not cryptographically secure. The device identifier was being used as a critical security boundary to bind subscription keys (JWT tokens) to specific devices.
**Learning:** Security boundaries must rely on robust cryptographic components. When an application's authentication or authorization relies on identifiers, they must be unpredictable. `Math.random()` generates values that are somewhat predictable, potentially allowing malicious actors to guess identifiers and compromise the validation flow.
**Prevention:** Always use a Cryptographically Secure Pseudo-Random Number Generator (CSPRNG) like `globalThis.crypto.getRandomValues()` instead of `Math.random()` when generating values related to identifiers, tokens, keys, passwords, or other security-sensitive information.
