## 2025-05-07 - [Security Enhancement] Replace Math.random() with CSPRNG for device_id
**Vulnerability:** Weak random number generation using `Math.random()` was used for creating a unique `device_id` in `src/util/subscription.js`. While it was only used as a unique identifier and not as a highly sensitive key, it is a security best practice to use a cryptographically secure pseudorandom number generator (CSPRNG) when generating unique identifiers for security contexts like subscription token validation.
**Learning:** `Math.random()` does not provide cryptographically secure random numbers and should not be used for anything related to security, including generating identifiers used for token binding. `self.crypto.getRandomValues()` is the web standard for CSPRNG.
**Prevention:** Use `self.crypto.getRandomValues()` whenever a secure random number is required in a client-side environment. Ensure the appropriate typed arrays are used to store the generated values. In this project's test environment, `global.self.crypto.getRandomValues` must be mocked in `src/setupTests.js` to prevent tests from failing due to the missing web crypto API.
